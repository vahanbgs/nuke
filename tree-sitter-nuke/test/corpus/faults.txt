================================================================================
A lone brace in an interpolation is a fault, and in a string it is not
:error
================================================================================

[$"a } b" "a } b"]

--------------------------------------------------------------------------------



================================================================================
A binding stands before a pair and never after one
:error
================================================================================

{a = 1 b := 2}

--------------------------------------------------------------------------------



================================================================================
A list holds values, and a binding is not one
:error
================================================================================

[a := 1]

--------------------------------------------------------------------------------



================================================================================
An escape letter is lowercase and a hex digit is not
:error
================================================================================

["\u{ff}" "\N"]

--------------------------------------------------------------------------------



================================================================================
A comma is not a separator, because there are none
:error
================================================================================

[1, 2]

--------------------------------------------------------------------------------
